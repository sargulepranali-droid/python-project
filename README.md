# Python Management Systems

Welcome to my Python project repository! This repository contains a collection of menu-driven applications developed using standard Python libraries. These projects demonstrate my foundational core programming concepts, data management capabilities, and logic implementation.

## 🚀 Key Projects Included
1. **Library Management System (File-Based & List-Based)**
   * Allows users to add, view, update, delete, and search books.
   * Utilized persistent File I/O operations and case-insensitive string parsing to efficiently access resources without data duplication.
2. **Student & Employee Records Management System**
   * Designed to streamline record tracking, automated log storage, and database manipulation.
   * Implemented structured control loops and exception-handling practices (try-except blocks) to process user arguments safely.

## 🛠️ Technical Competencies Demonstrated
* Object-Oriented Logic Structure
* Local File Persistence & Stream Operations
* Structured Search and Sort Paradigms
* Command-Line Interface (CLI) Optimization
